# Dependencies

If you are working with an app that is autogenerated, e.g. it has `just g` and various generation commands, then you should rely on `just deps` in order to do the dependency management.

If you are in the root directory, you can use just to navigate to a child directory, e.g. `just be deps upgrade` upgrades the BE dependencies.

If you are in a library, e.g. `codegen-targets`, that depends on another `codegen`, you can treat this much more normally.

Be aware that everything comes from CodeArtifact in CI, but is intended to come from editable sibling repositories when those exist.
